# compaction-recall agent conventions

- Read README.md for entrypoints and doc/PLUGIN.md for scope and limitations. archive/doc/FINDINGS.md records historical prototype results, not a fresh benchmark run. doc/benchmark.md documents the maintained, repository-owned runners and required external inputs.
- Runtime dependencies may be ordinary npm packages: declare them in package.json `dependencies` and lock them in package-lock.json. The Pi SDK and typebox stay host-provided peer dependencies. Never import from sibling worktrees or other paths outside the repository and its node_modules.
- src/index.ts is the public entry; src/recall-extension.ts remains an alternate compatibility entry. Do not register both at once or add root shims.
- src/history/history.mjs owns pure current-branch projection; src/history/locator.mjs owns shared rendering/context transformation. full uses the released SQLite in-memory engine and pure .mjs worker chain with branch-local visibility, lifecycle maintenance and awaited shutdown. Worker/engine failures propagate rather than changing retrieval algorithms. lite registers only history_grep/history_expand: no context injection, recall tool, worker or index hooks. jieba loads only in workers, once per worker, as jieba-wasm (bare name, else its explicit pkg/nodejs entry, because compiled OMP extension hosts ignore package.json main/exports); it only sets automatic-query word boundaries, and if it cannot load those boundaries use Intl.Segmenter with one stderr warning. The native @node-rs/jieba binding is no longer a dependency; archived prototypes that import it need it installed separately. No TypeScript loader, warning suppression, persistent index or model calls.
- src/extension/recall-config.mjs reads optional <getAgentDir()>/extensions/compaction-recall.json once at extension load for mode, preindex, retrieval limits, jieba and trace; see doc/PLUGIN.md for fields/env precedence. Import getAgentDir from the public SDK root; PI_CODING_AGENT_DIR selects the agent directory, not cwd or an SDK agentDir option. Read no project config. Missing file is silent. trace remains file-only, defaults false, and records structured concepts/match/exclude content only when enabled with COMPACTION_RECALL_TIMING_FILE. Reload after file/environment changes; lifecycle resets use loaded values. Tests must select isolated temporary agent directories before registration, never a personal profile.
- lite adds no hidden locator content to provider requests, though tool results can still be sent. The model must decide when to search; archived equivalent grep-only arms scored markedly lower in most comparisons, not every group, and were not rerun with this switch. Do not claim lite is faster. Both modes retain optional COMPACTION_RECALL_TIMING_FILE timing; lite emits only grep/expand call-chain stages. Configuration examples and SDK embedding details live in doc/PLUGIN.md.
- Preserve the concepts/match/exclude schema when changing mode selection. lite descriptions must not mention history_recall or locators. benchmark/grep-only-adapter.mjs remains frozen evaluation evidence; do not relabel archived results as mode-switch or 0.1 release runs.
- Run `npm ci --ignore-scripts` to install locked development dependencies and `npm run check` for type checking, offline behavior tests and isolated SDK loading.
- Keep all offline tests in test/. Run `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s test -p 'test_*.py'`; these tests use explicit synthetic helper/config/profile fixtures, never personal configuration or sibling worktrees.
- benchmark/run.py is the shared LME16-English/LME16-Chinese/SWE entrypoint, including generic --arm package and offline --stage preflight; benchmark/runner/prepare.py owns deterministic candidate/input freezing from one explicit model config, external data and existing snapshots. Use doc/benchmark.md for its prepare/pilot/all/flow workflow. No embedded provider/model defaults, personal profile copying or implicit .env loading. Original frozen evidence stays external and unchanged; public benchmark/data retains authorized Chinese questions and schema-projected non-text provenance/metrics, while archive holds historical implementations. Path/config changes must not relabel or resume historical runs. Never import runtime or benchmark support from sibling worktrees.
- doc/ holds current usage and historical method notes. README.md is the root index.
- Do not run benchmarks, live model calls, install into a user's Pi profile, publish, or change remote repositories without authorization.
- Release, only when asked: bump `version` by hand in package.json and both version fields of package-lock.json. Run `npm run check`, then `npm pack`, install the tarball into a temporary directory and load it in the compiled OMP extension host (`omp --mode rpc --no-extensions -e`, isolated HOME/XDG) to confirm the worker and jieba-wasm load without warnings. Commit `release: X.Y.Z`, create annotated tag `vX.Y.Z`, push main and the tag, and publish an English GitHub release with Changes and Evaluation sections. Run `npm publish --auth-type=web` in a real TTY without pipes or filters (otherwise npm exits with EOTP and no link); forward each confirmation URL at once (they expire in about five minutes). An expired token first needs `npm login --auth-type=web`, which is a separate confirmation. After `+ pi-compaction-recall@X.Y.Z`, allow a minute or two before the registry lists the version.
- The project is MIT licensed; preserve LICENSE, THIRD_PARTY_NOTICES.md and THIRD_PARTY_NOTICES.zh-CN.md. Keep npm files limited to production src, bilingual README, licenses and bilingual third-party notices; benchmark instructions live in doc/benchmark.md. Never package benchmark guides/results, tests, sessions, profiles or controller artifacts.
- The production analyzer NFKC-folds indexed text and queries, emits adjacent bigrams for Han/kana runs, whole lowercase words (ASCII camelCase/_/$ components) for other letters, numbers and marks, and also indexes dotted runs (10.0.0.1) whole; FTS5 uses `ascii tokenchars '.'` only to split the space-joined JS tokens. The index token stream ends every Han/kana run with a `\ue000` barrier; history_recall compiles each contiguous Han/kana run of a surface into one FTS5 phrase (other atoms stay AND co-occurrence), so phrases never span punctuation. English Porter stems stay. history_recall adds an exact dotted-run OR branch beside the fragment branch so partial runs keep matching. Results are ordered by BM25 then recency; there is no long-word reranking (offline A/B after phrase matching showed no benefit). Automatic queries use worker-side jieba word boundaries (Intl.Segmenter when disabled/unavailable), phrase each Han word, and alone filter the original STOPWORDS in src/search/sqlite-lexical.mjs; indexing and manual recall never filter that set. A usable automatic word is non-stopword and matches at least one visible compacted record, with no record-frequency eligibility ceiling. Only when the current message has no usable word may queries borrow up to four usable terms from the nearest eligible of two previous context user messages. Preserve the byte gates and current-only weighted autoGate; see doc/PLUGIN.md for the rules. Experimental S6 alternatives (porter-js, prefix-all and other strategy selectors) remain historical/prototype-only and never become production options. Production does not read COMPACTION_RECALL_SQLITE_ARM, BIGRAM_ONLY or HAN_PHRASE_TRIAL; legacy variables may remain in evaluation adapters. Keep experiment-only dependencies in devDependencies. Preserve measured frozen runs and their provenance.
