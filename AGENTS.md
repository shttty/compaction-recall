# compaction-recall agent conventions

- Read README.md for entrypoints and doc/PLUGIN.md for scope and limitations. archive/doc/FINDINGS.md records historical prototype results, not a fresh benchmark run. benchmark/INDEX.md indexes the maintained, repository-owned runners and required external inputs.
- Runtime dependencies may be ordinary npm packages: declare them in package.json `dependencies` and lock them in package-lock.json. The Pi SDK and typebox stay host-provided peer dependencies. Never import from sibling worktrees or other paths outside the repository and its node_modules.
- src/index.ts is the public entry; src/recall-extension.ts remains an alternate compatibility entry. Do not register both at once or add root shims.
- src/history/history.mjs owns pure current-branch projection; src/history/locator.mjs owns shared rendering/context transformation. full uses the released SQLite in-memory engine and pure .mjs worker chain with branch-local visibility, lifecycle maintenance and awaited shutdown. Worker/engine failures propagate rather than changing retrieval algorithms. lite registers only history_grep/history_expand: no context injection, recall tool, worker or index hooks. Native jieba loads only in workers; no TypeScript loader, warning suppression, persistent index or model calls.
- src/extension/recall-config.mjs reads optional <getAgentDir()>/extensions/compaction-recall.json once at extension load for mode, preindex, retrieval limits, jieba and trace; see doc/PLUGIN.md for fields/env precedence. Import getAgentDir from the public SDK root; PI_CODING_AGENT_DIR selects the agent directory, not cwd or an SDK agentDir option. Read no project config. Missing file is silent. trace remains file-only, defaults false, and records structured concepts/match/exclude content only when enabled with COMPACTION_RECALL_TIMING_FILE. Reload after file/environment changes; lifecycle resets use loaded values. Tests must select isolated temporary agent directories before registration, never a personal profile.
- lite adds no hidden locator content to provider requests, though tool results can still be sent. The model must decide when to search; archived equivalent grep-only arms scored markedly lower in most comparisons, not every group, and were not rerun with this switch. Do not claim lite is faster. Both modes retain optional COMPACTION_RECALL_TIMING_FILE timing; lite emits only grep/expand call-chain stages. Configuration examples and SDK embedding details live in doc/PLUGIN.md.
- Preserve the accepted 7820047 English aggregation guidance and concepts/match/exclude schema when changing mode selection. lite descriptions must not mention history_recall or locators. benchmark/grep-only-adapter.mjs remains frozen evaluation evidence; do not relabel archived results as mode-switch or 0.1 release runs.
- Run `npm ci --ignore-scripts` to install locked development dependencies and `npm run check` for type checking, offline behavior tests and isolated SDK loading.
- Keep all offline tests in test/. Run `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s test -p 'test_*.py'`; these tests use explicit synthetic helper/config/profile fixtures, never personal configuration or sibling worktrees.
- benchmark/run.py is the shared LME16/SWE entrypoint; benchmark/runner/prepare.py owns deterministic candidate/input freezing from one explicit model config, external data and existing snapshots. Use doc/benchmark.md for its prepare/pilot/all/flow workflow. No embedded provider/model defaults, personal profile copying or implicit .env loading. Original frozen evidence stays external and unchanged; public benchmark/data retains authorized Chinese questions and schema-projected non-text provenance/metrics, while archive holds historical implementations. Path/config changes must not relabel or resume historical runs. Never import runtime or benchmark support from sibling worktrees.
- doc/ holds current usage and historical method notes. README.md is the root index.
- Do not run benchmarks, live model calls, install into a user's Pi profile, publish, or change remote repositories without authorization.
- The project is MIT licensed; preserve LICENSE and THIRD_PARTY_NOTICES.md. Keep npm files limited to production src, bilingual README and licenses; benchmark instructions live in doc/benchmark.md and the source index in benchmark/INDEX.md. Never package benchmark guides/results, tests, sessions, profiles or controller artifacts.
- Release 0.1 fixes the measured English Porter plus raw Han bigrams strategy; jieba only ranks existing FTS candidates through han_rank SQL before pagination, never contributes exclude bonuses. Experimental S6 alternatives (porter-js, prefix-all and other strategy selectors) remain historical/prototype-only and never become production options. Production does not read COMPACTION_RECALL_SQLITE_ARM, BIGRAM_ONLY or HAN_PHRASE_TRIAL; legacy variables may remain in evaluation adapters. Keep experiment-only dependencies in devDependencies. Preserve measured frozen runs and their provenance.
