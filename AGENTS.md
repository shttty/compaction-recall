# compaction-recall agent conventions

- Read README.md for entrypoints and doc/PLUGIN.md for scope and limitations. doc/FINDINGS.md records historical prototype results, not a fresh benchmark run.
- Runtime dependencies may be ordinary npm packages: declare them in package.json `dependencies` and lock them in package-lock.json. The Pi SDK and typebox stay host-provided peer dependencies. Never import from sibling worktrees or other paths outside the repository and its node_modules.
- src/index.ts is the public entry; src/recall-extension.ts remains an alternate compatibility entry. Do not register both at once or add root shims.
- src/history.mjs contains pure current-branch history helpers; src/locator.mjs owns shared scan/ranking/rendering semantics. full (default) preserves worker-backed context/history_recall, live-token DF/N isolation, lifecycle maintenance, shared-scan failure fallback and awaited shutdown. lite registers only history_grep/history_expand: no context injection, recall tool, worker, pre-tokenization or index hooks. Worker dependencies remain shared pure JavaScript: no runtime TypeScript loader or warning suppression. No persistent index or model calls; experimental implementations must never enter production.
- src/recall-config.mjs reads optional <getAgentDir()>/extensions/compaction-recall.json once at extension load for mode, preindex and trace. trace is file-only, defaults to false and records query content into COMPACTION_RECALL_TIMING_FILE (src/recall-trace.mjs); with trace off, hooks, timing output and tool text stay byte-identical. Import getAgentDir from the public SDK root; PI_CODING_AGENT_DIR selects the agent directory, not process/session cwd or an SDK agentDir option. Read no project config. Missing file is silent; COMPACTION_RECALL_MODE and both COMPACTION_RECALL_PREINDEX_* variables override file values. Invalid mode falls back to full; invalid cadence overrides retain valid file/default values. Reload after file/environment changes; session_start/tree only reset counters using the loaded thresholds. Tests must set PI_CODING_AGENT_DIR to temporary directories before production registration, never access a personal profile.
- lite adds no hidden locator content to provider requests, though tool results can still be sent. The model must decide when to search; archived equivalent grep-only arms scored markedly lower in most comparisons, not every group, and were not rerun with this switch. Do not claim lite is faster. Both modes retain optional COMPACTION_RECALL_TIMING_FILE timing; lite emits only grep/expand call-chain stages. Configuration examples and SDK embedding details live in doc/PLUGIN.md.
- Keep full tool descriptions/parameter text byte-identical when editing mode selection. lite descriptions must not mention history_recall or locators. benchmark/grep-only-adapter.mjs is frozen evaluation evidence; do not change it or relabel archived results as mode-switch runs.
- Run `npm ci --ignore-scripts` to install locked development dependencies and `npm run check` for type checking, offline behavior tests and isolated SDK loading.
- Keep all offline tests in test/. Run `PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s test -p 'test_*.py'`; these tests use explicit synthetic helper/config/profile fixtures, never personal configuration or sibling worktrees.
- benchmark/evaluate.py requires an explicit external --config for real operations. No embedded provider/model defaults, personal profile copying or implicit .env loading. Keep frozen benchmark results and provenance byte-for-byte; path/config changes must not relabel or resume historical runs.
- doc/ holds current usage and historical method notes. README.md is the root index.
- Do not run benchmarks, live model calls, install into a user's Pi profile, publish, or change remote repositories without authorization.
- The project is MIT licensed; preserve LICENSE and THIRD_PARTY_NOTICES.md. Keep npm files limited to production src, bilingual README, licenses and the clean aggregate results doc; never package raw benchmarks, tests, sessions, profiles or controller artifacts.
